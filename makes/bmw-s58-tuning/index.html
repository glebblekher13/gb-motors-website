Questions

S58 FAQ

Does my S58 need an ECU unlock?

Newer BMWs often need the engine computer unlocked before it can be flashed. It depends on build date and software. We'll check your car and handle it if needed.

Can you set up an S58 for track days?

Yes. Along with the tune, we handle cooling, brakes, alignment and the checks a car needs before a track day.

Is the S58 safe on ethanol?

With the right tune and fuel system for the blend, ethanol is one of the best upgrades for an S58. We'll set up the blend your fuel system can support.
